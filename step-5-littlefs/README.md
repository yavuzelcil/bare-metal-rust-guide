# Step 5: LittleFS File System

Bu adımda embedded sistemler için tasarlanmış LittleFS dosya sistemini entegre ediyoruz.

## Hedefler

- Flash bellek üzerinde dosya sistemi
- Dosya okuma/yazma işlemleri
- Power-safe dosya sistemi operasyonları
- Wear leveling desteği

## Kullanım

```bash
cd step-5-littlefs
cargo build --release
cargo run --release
```
