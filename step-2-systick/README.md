# Step 2: SysTick Timer

Bu adımda ARM Cortex-M SysTick timer'ı kullanarak hassas zamanlama yapıyoruz.

## Hedefler

- SysTick register'larını yapılandırma
- Interrupt handler tanımlama
- Milisaniye bazlı delay fonksiyonları

## Kullanım

```bash
cd step-2-systick
cargo build --release
cargo run --release
```
