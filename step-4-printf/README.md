# Step 4: Printf Implementation

Bu adımda `printf` benzeri formatlı çıktı desteği ekliyoruz.

## Hedefler

- Rust'ın `core::fmt` trait'lerini implement etme
- UART üzerinden formatlı string yazdırma
- `write!` ve `writeln!` makrolarını kullanma
- Debug çıktıları için altyapı

## Kullanım

```bash
cd step-4-printf
cargo build --release
cargo run --release
```
